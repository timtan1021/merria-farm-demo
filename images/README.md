# 写真素材について

このディレクトリの写真は、**すべて既存の公式サイト
（https://merriafarm.shop-pro.jp/ ）に店舗自身が掲載しているもの**です。
`tools/fetch-images.sh` で取得しました。口コミサイト・Google の投稿写真・
SNS の写真は1枚も使っていません。AI生成の写真も使っていません。

## 扱い上の注意

- **写真は店舗の著作物を借りている状態。** 営業メールにその旨と
  「ご不快であればすぐ取り下げる」ことを明記する
- **最大でも400pxしかない。** 元の寸法を超えて表示しない
  （`test/lib/check-upscale.py` が引き伸ばしを検出する）。
  提案が通ったら撮り直しが前提
- 店舗のご案内ページにある `annai03_a/b/d.jpg`（100px以下の小さな写真）は
  小さすぎるため使っていない

## 撮り直しで確認したいもの

| 撮るもの | 何が確定するか |
|---|---|
| メニュー看板・価格表 | 全品目と現在価格（要確認 #1） |
| ソフトクリーム本体 | ヒーローに置く1枚。配色の採取元 |
| 線路側のテラス（電車が写るもの） | この店だけの一枚。横位置で |
| 外観と木の看板 | 現在の top_photo0 の差し替え |
| 支払い方法の掲示 | 要確認 #3 |

撮ったあとは、写真に実在する色を拾って `css/tokens.css` の色トークンだけを
差し替え、`bash test/run-all.sh` でコントラスト検証を通す。
